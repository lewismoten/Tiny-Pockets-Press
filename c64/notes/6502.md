# 6502 Notes

These are compact working notes for the 6502-family code used by the C64 loader.

## Registers

- `A`: accumulator
- `X`: index register X
- `Y`: index register Y
- `PC`: program counter
- `SP`: stack pointer
- `P`: processor status

## Common Instructions Used In The Loader

## Instruction Usage Notes

### `LDA`

Loads a value into the accumulator. Use it before arithmetic, comparisons, or stores.

```asm
LDA #$20      ; A = $20
STA $d020     ; border color = 32 decimal color entry
```

### `LDX`

Loads the X register. Commonly used for loops, indexing, or KERNAL parameters.

```asm
LDX #$08      ; device 8
JSR $ffba     ; often used after A/Y were prepared for SETLFS
```

### `LDY`

Loads the Y register. Often paired with `LDA` and `LDX` for pointer setup or indexed access.

```asm
LDY #$00      ; start at offset 0
LDA ($fb),Y   ; read byte from pointer in $fb/$fc plus Y
```

### `STA`

Stores the accumulator into memory.

```asm
LDA #$00
STA $d021     ; set background color to black
```

### `STX`

Stores the X register into memory.

```asm
LDX #$19
STX $c927     ; save a band counter or config value
```

### `STY`

Stores the Y register into memory.

```asm
LDY #$00
STY $02       ; clear a zero-page temporary
```

### `ADC`

Adds a value to `A` plus the carry bit. Clear carry first when doing normal addition.

```asm
CLC           ; important for plain addition
LDA $fb
ADC #$40      ; add 64
STA $fb
```

### `SBC`

Subtracts a value from `A` using the carry bit. Set carry first for plain subtraction.

```asm
SEC           ; important for plain subtraction
LDA $fc
SBC #$01      ; subtract 1
STA $fc
```

### `CMP`

Compares `A` with a value or memory location. It does not change `A`; it only changes flags.

```asm
LDA $90
CMP #$40      ; compare status with EOF bit pattern
BEQ done
```

### `AND`

Masks bits. Useful for keeping only the bits you care about.

```asm
LDA $dd00
AND #$fc      ; clear low two VIC bank bits
```

### `ORA`

Sets bits by OR-ing them into the existing value.

```asm
LDA $dd00
ORA #$02      ; select desired VIC bank bits
STA $dd00
```

### `EOR`

Toggles or compares differences between bits.

```asm
LDA $d020
EOR #$01      ; flip the low bit for a simple flash effect
STA $d020
```

### `INC`

Increments a memory location by 1.

```asm
INC $c900     ; bump status or counter byte
```

### `DEC`

Decrements a memory location by 1.

```asm
DEC $c927     ; count bands down toward zero
BNE bandLoop
```

### `INX`

Increments X by 1.

```asm
LDX #$00
INX           ; X = 1
```

### `INY`

Increments Y by 1, often while walking a buffer.

```asm
LDA ($fb),Y
INY           ; move to the next byte in the current page
```

### `DEX`

Decrements X by 1. Common for compact loops.

```asm
LDX #$08
loop:
DEX
BNE loop
```

### `DEY`

Decrements Y by 1.

```asm
LDY #$10
DEY
BNE keepGoing
```

### `ASL`

Shifts bits left. Bit 7 moves into carry.

```asm
LDA #$04
ASL A         ; A becomes $08
```

### `LSR`

Shifts bits right. Bit 0 moves into carry.

```asm
LDA #$80
LSR A         ; A becomes $40
```

### `ROL`

Rotates left through carry. Useful for multi-byte shifts.

```asm
CLC
LDA #$81
ROL A         ; carry receives old bit 7, carry also enters bit 0
```

### `ROR`

Rotates right through carry.

```asm
SEC
LDA #$02
ROR A         ; carry shifts into bit 7
```

### `CLC`

Clears carry. Use before plain addition or when explicitly reporting success with carry clear.

```asm
CLC
ADC #$01      ; add without a stale carry
```

### `SEC`

Sets carry. Use before plain subtraction or when reporting an error condition through carry set.

```asm
SEC
SBC #$01      ; subtract without borrow
```

### `BEQ`

Branches when the zero flag is set.

```asm
CMP #$00
BEQ noData    ; branch if equal to zero
```

### `BNE`

Branches when the zero flag is clear.

```asm
DEC $c927
BNE bandLoop  ; keep going until counter reaches zero
```

### `BCC`

Branches when carry is clear. Common success path after a subroutine that signals failure with carry set.

```asm
JSR readByte
BCC byteOk    ; branch if read succeeded
```

### `BCS`

Branches when carry is set.

```asm
JSR openFile
BCS openFailed
```

### `BMI`

Branches when the negative flag is set.

```asm
LDA result
BMI valueWasNegative
```

### `BPL`

Branches when the negative flag is clear.

```asm
LDA result
BPL valueWasPositiveOrZero
```

### `JMP`

Jumps unconditionally to another address.

```asm
JMP mainLoop   ; continue without returning
```

### `JSR`

Calls a subroutine and expects that subroutine to end with `RTS`.

```asm
JSR streamSegment   ; do the work
BCC done            ; then inspect flags/result
```

### `RTS`

Returns from a subroutine previously entered with `JSR`.

```asm
success:
CLC                 ; report success
RTS
```

### `PHA`

Pushes `A` onto the hardware stack. Useful when you need to preserve `A`.

```asm
LDA $90
PHA           ; save status byte while doing other work
```

### `PLA`

Pulls the top byte from the stack back into `A`.

```asm
PLA           ; restore saved A value
STA $c900
```

| `SEI` | `SEI` | `$78` | `0` | `1` | set interrupt disable |

### `TAX`

Copies `A` into `X`. Useful when a value in `A` needs to become a loop counter or index.

```asm
LDA #$28
TAX           ; X = 40
```

### `TAY`

Copies `A` into `Y`.

```asm
LDA #$00
TAY           ; Y = 0
```

### `TSX`

Copies the current stack pointer into `X`. Handy for stack-aware debugging or stack frame tricks.

```asm
TSX           ; X now reflects current stack depth position
STX $c900
```

### `TXA`

Copies `X` into `A`.

```asm
LDX #$08
TXA           ; A = 8
```

### `TXS`

Copies `X` into the stack pointer. Use with care, because it directly changes stack behavior.

```asm
LDX #$ff
TXS           ; reset stack pointer to top of stack page
```

### `TYA`

Copies `Y` into `A`.

```asm
LDY #$10
TYA           ; A = 16
```

### `BIT`

Tests memory bits against `A` without changing `A`. Also copies memory bit 7 to `N` and bit 6 to `V`.

```asm
LDA #$20
BIT $d011     ; test whether matching bits are set in VIC control register
BEQ bitWasClear
```

### `CPX`

Compares `X` against a value or memory location.

```asm
LDX #$05
CPX #$08
BCC stillBelowTarget
```

### `CPY`

Compares `Y` against a value or memory location.

```asm
LDY #$19
CPY #$19
BEQ reachedLastBand
```

### `BRK`

Forces a software interrupt. On the C64 this is usually something to avoid in shipping loader code unless you deliberately want the break behavior.

```asm
BRK           ; stop and enter break/interrupt handling
```

### `RTI`

Returns from an interrupt handler, restoring flags and the program counter from the stack.

```asm
irqDone:
RTI           ; return from IRQ, not from JSR
```

### `PHP`

Pushes the processor status register onto the stack.

```asm
PHP           ; save flags before temporary flag-changing work
```

### `PLP`

Restores the processor status register from the stack.

```asm
PLP           ; restore saved flags
```

### `NOP`

Does nothing except consume time and one byte.

```asm
NOP           ; small timing pad or placeholder
```

### `CLD`

Clears decimal mode. Good defensive setup if you do not want BCD arithmetic behavior.

```asm
CLD           ; ensure normal binary ADC/SBC behavior
```

### `SED`

Sets decimal mode so `ADC` and `SBC` perform BCD-style arithmetic.

```asm
SED           ; turn on decimal arithmetic
```

### `CLI`

Clears the interrupt-disable flag, allowing maskable IRQs again.

```asm
CLI           ; re-enable IRQ handling
```

### `SEI`

Sets the interrupt-disable flag, blocking maskable IRQs.

```asm
SEI           ; prevent IRQs during a critical section
```

### `CLV`

Clears the overflow flag.

```asm
CLV           ; reset overflow before logic that inspects V
```

### `BVC`

Branches when the overflow flag is clear.

```asm
BVC noOverflowPath
```

### `BVS`

Branches when the overflow flag is set.

```asm
BVS overflowPath
```

## Important Status Flags

- Carry: used heavily for arithmetic and success/error branching.
- Zero: often used for loop termination.
- Negative: result high bit.
- Overflow: signed arithmetic edge cases.

## Addressing Modes Seen Often

| Mode | Example | Operand bytes after opcode | Notes |
| --- | --- | --- | --- |
| immediate | `LDA #$20` | `1` | value is embedded directly in the instruction |
| absolute | `STA $d020` | `2` | full 16-bit address follows the opcode |
| zero page | `LDA $fb` | `1` | shorter and faster for addresses `$00-$ff` |
| indexed | `LDA $4000,X` | `2` | base address plus register offset |
| indirect indexed | `LDA ($fb),Y` | `1` | pointer from zero page, then add `Y` |

## Loader Coding Patterns

- use carry clear for success and carry set for failure
- preserve zero-page pointers before borrowing them
- copy big chunks with pointer pairs plus a length counter
- call KERNAL for IO and keep custom code focused on memory movement
